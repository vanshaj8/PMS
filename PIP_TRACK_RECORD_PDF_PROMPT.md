# Prompt for Cursor: PIP Track Record PDF Generation

## Feature Request: PIP Track Record PDF Document

Create a comprehensive PDF generation feature for PIP (Performance Improvement Plan) track records that generates a professional document similar to an annual appraisal letter. This PDF should document the complete PIP workflow, progress, and outcomes.

### Requirements:

#### 1. **PDF Generation Backend Endpoint**
- Create a new endpoint: `GET /api/pips/{pipId}/track-record-pdf`
- Use a Java PDF library (e.g., Apache PDFBox, iText, or OpenPDF)
- Generate PDF on-the-fly from PIP data
- Return PDF as downloadable file with proper headers

#### 2. **PDF Document Structure**

The PDF should include the following sections in a professional format:

**Header Section:**
- Company logo/header
- Document title: "Performance Improvement Plan - Track Record"
- PIP ID, Employee Name, Employee ID
- Manager Name, HRBP Name
- Document generation date

**Executive Summary:**
- PIP start date and end date (if completed)
- Current status
- Overall outcome (Successful/Failed/Extended/In Progress)
- Success score percentage (if completed)
- Key highlights

**Timeline & Workflow Progress:**
- Visual timeline showing all workflow steps
- Step-by-step breakdown:
  - HRBP Initial Review (with approval date and comments)
  - Employee Acknowledgement (with acknowledgement date)
  - Active PIP Period (start date, end date, duration)
  - Employee Self-Review (submission date, key points)
  - Manager Review (completion date, feedback)
  - HRBP Final Decision (decision date, outcome)
- Status of each step (Completed/Pending/Overdue)
- Actual vs. planned deadlines

**Goals & Objectives:**
- List all goals with:
  - Goal title and description
  - Weightage percentage
  - Expected outcome
  - Actual achievement status (Achieved/Partially Achieved/Not Achieved)
  - Manager comments on each goal
  - Employee justification (if provided)

**Check-in History:**
- Table showing all check-ins:
  - Check-in date
  - Progress notes
  - Employee feedback
  - Manager feedback
  - Status/outcome

**Performance Metrics:**
- Success criteria breakdown:
  - Minimum required score
  - Actual achieved score
  - Calculation method (weighted average)
  - Per-goal contribution
- Visual charts/graphs (if possible):
  - Goal achievement pie chart
  - Timeline Gantt chart
  - Progress trend line

**Review & Feedback:**
- Employee Self-Review summary
- Manager Review summary
- HRBP Final Decision and rationale
- Key improvement areas identified
- Strengths acknowledged

**Extension History (if applicable):**
- Number of extensions used
- Extension reasons
- Original vs. extended timeline

**Compliance & Metadata:**
- Timeline version history
- SLA attribution (delays and responsible parties)
- Compliance mode (Standard/Strict/Local Law)
- Escalation history (if any)

**Footer:**
- Document classification (Confidential/Internal)
- Generated by: System
- Page numbers
- Disclaimer text

#### 3. **Styling & Formatting**

- Professional layout with:
  - Consistent fonts (Arial or Times New Roman)
  - Proper spacing and margins
  - Company color scheme (if applicable)
  - Headers and subheaders with hierarchy
  - Tables with borders and alternating row colors
  - Page breaks to avoid splitting sections awkwardly
  - Watermark (optional): "CONFIDENTIAL" or "INTERNAL USE ONLY"

#### 4. **Frontend Integration**

- Add a "Download Track Record PDF" button on:
  - PIP Detail Page (for employees, managers, HRBP, admins)
  - PIP List Page (bulk download option for admins)
- Show loading state while generating PDF
- Handle errors gracefully with user-friendly messages
- Support for different user roles (show appropriate sections based on permissions)

**Backend (Java/Spring Boot):**

    // 1. Fetch PIP with all related data (goals, steps, check-ins, etc.)

**PDF Library Options:**
- Apache PDFBox (recommended - free, open source)
- iText (commercial license required for commercial use)
- OpenPDF (free alternative to iText)

**Data to Include:**
- Complete PIP entity with all relationships
- All PIP steps with dates and statuses
- All goals with status and comments
- All check-ins with dates and notes
- Metadata (success criteria, timeline versions, etc.)
- User information (employee, manager, HRBP)

#### 6. **Additional Features**

- **Email Integration**: Option to email PDF directly to stakeholders
- **Archive Versioning**: Save generated PDFs with version numbers
- **Custom Templates**: Allow different PDF templates for different PIP types
- **Multi-language Support**: Support for different languages (future enhancement)
- **Digital Signature**: Add signature fields for formal acknowledgment (future enhancement)

#### 7. **Error Handling**

- Handle cases where PIP data is incomplete
- Graceful degradation if certain sections don't have data
- Clear error messages if PDF generation fails
- Logging for debugging PDF generation issues

#### 8. **Performance Considerations**

- Cache generated PDFs (optional) for frequently accessed PIPs
- Optimize PDF size (compression)
- Generate PDF asynchronously for large documents (optional)
- Set appropriate timeout limits

### Expected Output:

A downloadable PDF file named: `PIP_TrackRecord_{EmployeeName}_{PIPId}_{Date}.pdf`

Example: `PIP_TrackRecord_JohnDoe_PIP-2025-001_2025-12-19.pdf`

### Success Criteria:

1. ✅ PDF generates successfully for any PIP (completed or in-progress)
2. ✅ All workflow steps are documented with dates
3. ✅ Goals and check-ins are clearly presented
4. ✅ Professional formatting matches appraisal letter standards
5. ✅ PDF is downloadable from frontend
6. ✅ Works for all user roles with appropriate permissions
7. ✅ Handles edge cases (missing data, incomplete PIPs)
8. ✅ PDF file size is reasonable (< 5MB for typical PIP)

### Implementation Priority:

1. **Phase 1**: Basic PDF generation with core sections (Header, Timeline, Goals, Check-ins)
2. **Phase 2**: Add charts/graphs and advanced formatting
3. **Phase 3**: Email integration and archiving
4. **Phase 4**: Custom templates and advanced features
